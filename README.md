# 足球分析报告

基于 Python 泊松分布 + Elo + 机器学习模型的足球分析系统（预测胜负/比分、球队强弱、球员表现、真实盘口），每日自动更新。

## 使用

打开 **https://lc815814.github.io/football-report/** 即可查看最新报告。

## 自动更新机制（双保险）

| 通道 | 时间（北京时间） | 运行位置 | 说明 |
|---|---|---|---|
| 本机精确实时更新 | 每天 14:15 | 你的电脑 | 多源核实补录（FBref + 搜索交叉确认），数据最完整准确 |
| 云端兜底更新 | 每天 17:00 | GitHub 服务器 | 自动同步 openfootball 官方源，**电脑关机也照常更新** |

任一通道有新增比赛，报告会自动重新生成并发布，线上约 1 分钟后生效。

## 功能

- 预测比赛胜负 / 比分 / 总进球数
- 评估球队强弱（排名、攻防能力、Elo）
- 球员表现分析
- 真实盘口（竞彩官方接口）
- 覆盖：英超/西甲/德甲/意甲/法甲/葡超/荷甲/日职/韩职/欧冠

## 换电脑 / 数据清除后恢复

下载仓库中的 **`一键恢复-新电脑.bat`** 到新电脑双击运行，即可自动完成：
Git 安装（如缺）→ 下载全部数据与代码 → 安装 Python 依赖 → 生成最新报告。
之后在豆包里说一句"重建足球定时任务"即可恢复每日自动更新。

## 仓库结构

- `index.html` — 发布的报告（根目录，GitHub Pages 直接服务）
- `cloud_update.py` — 云端自动更新脚本（openfootball 合并 → 生成 → 发布）
- `football_model/` — 模型与报告生成代码
- `football_data/` — 各联赛数据（2023/24、2025/26、2026/27、日职、韩职、欧冠）
- `.github/workflows/pages.yml` — Pages 自动部署
- `.github/workflows/cloud-update.yml` — 云端每日兜底更新
